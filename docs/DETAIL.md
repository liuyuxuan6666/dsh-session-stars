# 会话星标 / Session stars

给你的会话列表加个星标，然后把标过的会话集中到一个页面里。

## 它解决什么

DSH 的左侧会话列表按工作区和时间排，任务一多就找不到"那几条正在跟的"。归档会把会话移出列表，置顶只能压住工作区顶部几条；两者都不是"临时标记"。

星标是第三种：不动会话本身、不影响排序，只是在你自己的清单里记一笔。想看的时候，左上角「星标」点开就是一个列表。

## 用起来是什么样

**会话行**：鼠标移到任意会话行，行尾「更多 / 归档 / 置顶」这一排多一个星标按钮。

- 未标星：空心星，灰色（`--dsw-alias-label-secondary`）。
- 已标星：实心星，品牌色（`--dsw-alias-brand-primary`）。
- **标完不会消失**：时间标签后面留一颗常驻的小实心星，鼠标移开也在，点它就能取消（行尾那排按钮是悬停才出现的，标完就藏起来会让人以为没生效）。
- 立即生效（乐观更新）；请求失败会回滚，并把原因显示在星标页顶部。

**「…」菜单**：多一条「加星标 / 取消星标」。悬停按钮在无悬停设备上会被隐藏，菜单是那条路。

**星标页**：左侧栏面板入口点「星标」。按工作区分组，每组一行会话：

- 标题（读取会话日志里的最新标题），过长省略；
- 「加星于 11月19日 14:20」；
- 会话已不存在或被清掉时，右侧标一枚「会话不可用」——星标不会替你假装它还在；
- 行尾「取消星标」。

空列表时给一句怎么标星的提示，而不是一张白页。

## 数据放在哪

`$DSH_HOME/session-stars/stars.json`：

```json
{
  "version": 1,
  "updated": "2026-11-19T06:20:00.000Z",
  "items": [
    { "sessionId": "…", "title": "…", "cwd": "C:/…", "starredAt": "2026-11-19T06:10:00.000Z" }
  ]
}
```

- 写入走"临时文件 + rename"，进程被杀不会留半个 JSON。
- 文件坏了会被挪成 `stars.json.corrupt-<时间戳>`，面板当空列表继续跑，不崩。
- 单个会话重复标星不会产生两条；`starredAt` 保留第一次标星的时间。

## 已知边界

- 只列出，不回跳：点星标页里的行不会跳到会话（按当前需求刻意不做）。
- 标记只在这台机器的这个 `DSH_HOME` 里，不做跨设备同步。
- 会话被删除后星标仍在（标为「会话不可用」），需要你手动取消。
- 标题取自会话日志，重命名后要重新打开星标页才会更新（页面每次进入会刷新一次）。
